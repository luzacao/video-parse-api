**问：快手口令解析失败，第一步该干什么？**

答：先别动接口，把「输入内容」检查一遍。快手口令通常是「7.43 复制打开快手，看看…」这样一整段话，里面藏着 `v.kuaishou.com` 开头的短链。很多人为了「干净」，只把短链抠出来传过去，这反而容易失败——快手部分链接需要完整口令才能定位到作品。所以第一招：**把整段分享文案原样丢进去**，不要自己拼。

**问：链接是完整的，也试了全文，还是报 400 怎么办？**

答：看两件事。第一，链接是不是「分享链接」而不是「浏览器地址栏的链接」？快手 App 里点「分享-复制链接」得到的才是合法输入；如果你是在电脑上右键复制的网页地址，接口可能不认识。第二，确认链接没被截断，特别是 `v.kuaishou.com/` 后面的那串字符，漏一个字母都解析不了。

**问：输入没问题，返回 404 是什么意思？**

答：404 代表内容可能已删除或私密。快手有些视频作者设置了「仅粉丝可见」或「好友可见」，这种即使链接有效，服务端也拿不到数据。这时候没别的办法，只能让发布者把视频设为公开，或者换个作品试试。

**问：拿到 429 错误，是接口挂了吗？**

答：不是挂，是限流了。短视频去水印 API 的[体验站](https://video.zacao.top)首页可以不带 Key 试用，但每个 IP 每小时只能请求 30 次，超了就返回 429。这个设计是为了防止有人拿体验接口刷量。如果你在办公室或共用网络下测试，经常会出现「刚才还好的，突然就不行了」——大概率是同一个出口 IP 被别的同事用完了额度。解决办法很简单：等一小时，或者直接去[购买页](https://video.zacao.top/buy)拿个 Key，正式对接就不受这个限制。

**问：那拿到了 Key，请求格式写对了吗？**

答：这是最多人踩的坑。Base URL 固定是 `https://video.zacao.top`，解析接口是 `POST /api/parse`，Header 里必须带 `X-API-Key`，值就是你买的 `mp_` 开头的 Key。注意，是 Header 不是 Query 参数，别写错位置。给你个最小可用的 curl 示例：

```bash
curl -X POST 'https://video.zacao.top/api/parse' \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: mp_你的Key' \
  -d '{"text":"7.43 复制打开快手，看看https://v.kuaishou.com/xxxxx/"}'
```

**问：代码看着没问题，但一直 403，为什么？**

答：403 分两种情况。一是 Key 真的无效或过期，检查一下是不是复制多了空格。二是内容本身不可访问，比如快手对某些站内视频做了 Referer 校验，接口抓取时被源站拒了。这种属于平台风控，不是你的问题，换个作品再试通常就好了。另外提醒一句，`/api/parse` 返回的 `video_url` 有时会是站内代理路径，这是正常的，直接播放即可；要是遇到防盗链，还可以调 `/api/video/stream` 用 Referer 参数二次拉取。

**问：有没有办法快速确认服务是活的？**

答：有，直接访问 `https://video.zacao.top/api/health`，返回正常就说明服务在线。然后再检查你的入参。这里放一张常见错误速查表，比看文档快：

| 现象 | 优先排查 | 解决动作 |
| --- | --- | --- |
| 400 参数错误 | 链接格式、是否完整口令 | 重新复制分享文案，整段传入 |
| 404 资源不存在 | 作品是否公开 | 换一个公开作品测试 |
| 429 限流 | 匿名 IP 小时额度 | 等一小时或购买 Key |
| 403 禁止访问 | Key 有效性 / 源站风控 | 核对 Key，换作品重试 |
| 超时无响应 | 网络环境 | 确认能访问外网，重试一次 |
